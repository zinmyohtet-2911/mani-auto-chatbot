> A friendly Burmese-speaking chatbot built with React and Vite.

---

## 📖 About

Mani is a simple chatbot interface that responds to user messages with a friendly, playful personality. This project was built as a learning exercise to practice React fundamentals including state management, event handling, conditional rendering, and component styling.

---

## ✨ Features

- 💬 Interactive chat interface with send button and Enter key support
- 🎨 Red-themed responsive UI with smooth animations
- ⚡ Auto-scroll to the latest message
- 🔢 Count-based replies that change with each message
- 📱 Mobile-friendly design
